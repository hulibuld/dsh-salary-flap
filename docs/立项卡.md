# 立项卡 ·「工资跳板」Salary Flap

> 这份文件是整个团队的唯一事实源。所有成员开工前必读；有冲突以本文为准，本文没写的找主控。

## 1. 一句话

把「我这一秒正在赚多少钱」做成一块挂在 DeepSeek Harness 网页界面上的翻牌看板：输入月薪、每天工作几小时、每月工作几天，板子每 2 秒结算一次，数字像机场翻牌一样跳，显示今天已经赚了多少钱（两位小数）。

## 2. 给谁用

给「在电脑前上班、写作业、备考」的人一个可视化的时间变现反馈。装进 Harness Web UI 自己用，不是公开发布的产品。

## 3. 交付形态（硬约束）

- **DSH bundle（prism 插件包）**，装进当前 profile（`desktop`）。
- **渲染位置：Client Slot `shell.overlay`**（frame-wide floating layer，click-through，条目自己 opt-in pointer events）。
  - 注册参数：`{ name: 'shell.overlay', id: 'salary-flap', order: <数字> }`；`id`/`order` 必填，`label` 可选（纯展示元信息，会出现在 slot 树里，便于装完核验）。不要抢别人的 id。
- **纯前端**：无 Host 服务、无网络请求、无凭据、无 telemetry。配置存浏览器 `localStorage`。
- 包名 `@local/dsh-salary-flap`，版本 `0.1.0`，`private: true`，`type: module`。

## 4. 计算模型（必须精确照此实现）

```
日薪      = 月薪 / 每月工作天数
时薪      = 日薪 / 每日工作小时数
每秒进账  = 时薪 / 3600
每 2 秒结算一次 = 时薪 / 1800   ← 显示值只在 2 秒格点上跳一次
```

今日已赚（`earnedToday`）的取值：

1. 现在 < 上班时间 → `0`
2. 上班时间 ≤ 现在 < 下班时间 → `日薪 × 已过去的计薪秒数 / 当日总计薪秒数`
3. 现在 ≥ 下班时间 → `日薪`（封顶，不再增长）

其他规则：

- 下班时间 = 上班时间 + 每日工作小时数。若跨零点（结束时刻 ≤ 开始时刻），按跨午夜班次处理：把「现在」归一到班次起点之后的偏移量再算进度。
- 显示值必须**截断**（不是四舍五入）到两位小数，避免出现 0.005 被显示成 0.01 的跳变错觉。金额用 `¥12.34` 形态。
- 只有「正在上班」时才每 2 秒跳一次。没上班显示 0.00 + 一行灰字「还没上班」；收工后显示封顶值 + 灰字「今天收工了」。
- 所有时间按**本机本地时区**计算，不联网对时。

## 5. 交互（必须直观，用户不看说明书就会用）

- **首次出现 = 设置态**：板子上直接是三个输入框（月薪 ¥、每日工时 h、每月工作天数 d）+ 上班时间（默认 09:00）+ 一个「开始跳」按钮。不要做成必须点齿轮才能进的设置页。
- **跑起来之后**：板子显示大号翻牌金额，下面一行小字「时薪 ¥xx.xx · 今日进度 xx%」，右上角一个极小的齿轮。
- **齿轮**（或右键）打开设置面板，可以改参数，改完即时生效。
- **可拖动**：按住板子顶部拖动位置，位置存 `localStorage`。
- **可折叠**：右上角一个「—」收起成一条小横条（只显示金额），再点展开。
- 板子不能挡住下方界面交互：`shell.overlay` 是整帧浮层，**外层容器必须 `pointer-events: none`**（否则透明区域会吃掉整页点击），**只有内层卡片 `pointer-events: auto`**。写反就是 P0，整个 Harness 界面点不动。

## 6. 翻页动画（这是本插件的卖点，必须做好）

- 每个数字位一张**分片翻牌（split-flap）**：卡片分上下两半，数字变化时上半页沿底边向下翻到 -90°，紧接着新数字的下半页从 +90° 翻回 0°。
- 动画时长 **420ms**（半程 210 + 210；v0.4 起从 220ms 加长——用户实测 220ms 只像「换了张图」，看不出翻页）。前半程 `cubic-bezier(.45,0,.9,.45)`（加速下落），后半程 `cubic-bezier(.2,.9,.3,1)` 且末段 78% 处 `rotateX(-6deg)` 回弹，亮度 1 → .45 → 1。`perspective: 420px` 打在牌容器，半页 `backface-visibility: hidden`。
- 牌面必须读起来像**一整块机械翻牌窗**，不是「深色底板 + 一排骨牌」：整行包在 `.sf-board`（凹陷窗：内阴影 + 板底色压深），每格 2px 铰链线 + 上沿反光，上半页比下半页亮一档。
- 只有变化的位才翻（十进制进位时从右往左逐位翻），没变的位保持静止。
- 金额整体在每次结算时有一次 1–2px 的轻微上浮（`transform: translateY`）次要动效，不能抖。
- 必须尊重 `prefers-reduced-motion: reduce`：直接跳值不翻牌。
- 数字用等宽（`font-variant-numeric: tabular-nums` 或等宽字体栈），否则翻牌宽度会跳。

## 7. 视觉

- 宿主界面部分（顶栏胶囊 `sf-chip`）只用主题 token：底色 `--dsw-alias-bg-layer-2`、描边 `--dsw-alias-border-l1`、文字 `--dsw-alias-label-primary`、呼吸灯 `--dsw-alias-state-success-primary`/`--dsw-alias-state-idle-primary`。
- **牌面例外（v0.3 用户决定）**：看板本体用六套**字面色板**，不用 token——牌面要和身后界面明显分开才像实体小牌，token 只表达界面层级，做牌面会糊成一片。六套：`mono` 黑白灰、`green` 护眼绿、`wood` 原木黄、`sky` 天空浅蓝、`night` 暗夜黑、`sakura` 樱粉。每套六个键（bg/slat/text/accent/border/muted）见 `client.js` 的 `THEMES`。配色圆点排在顶栏标题右边、工具键左边，点一下即时换色。
- 板子走「深色翻牌机」质感：深底 + 1px 描边 + 内阴影，圆角 15px，宽度 280px，右下角默认位置（距右 24px、距下 96px）。
- 牌面固定 **8 格**：`¥` + 4 个整数位 + `.` + 2 位小数（日薪上限按 ¥9999.99 算，用户口径）。字面 40px，`¥` 与小数点占 `.46em` 的窄格，数字位 `.78em`，位数不足补空槽（只占宽度、不画牌面），整行宽度恒定。
- 牌面内的明暗过渡用 `linear-gradient` + `rgba` 黑白叠加实现，不要给牌面引 token；宿主界面部分仍禁止写死主题色。
- **整块板就是一台翻牌器（v0.4 用户要求）**：金额行外面必须有凹陷底窗（`inset 0 2px 7px rgba(0,0,0,.62)`），每格牌面有 2px 中缝 + 上沿反光，半程 210ms、全程 420ms、落定 `-6deg` 回弹、亮度压到 `.45`。只加画布不算，必须是会翻的牌。
- **拖到 DSH 外的弹出窗（`window.html`）与看板同款牌面**：8 格、窄格、中缝、`perspective:420px`、同样的时长与曲线，小窗字号 34px 等比缩小。一致性由 `node /tmp/sf-win-geom.mjs` 断言（14 项）。
- 文案全部走 Client locale 服务，中英双语（`locale/zh.json`、`locale/en.json`）。

## 8. 边界与非目标

- **不做**：午休剔除、多份工作、跨天累计历史、图表、导出、托盘、开机自启、账号同步、声音。
- 不依赖任何第三方 npm 包（client.js 里只用 ModuleLoader 给的 React）。
- 不 `require` 任何 Harness Client 包，不往 `document.body` 追加节点，不写全局 CSS。
- 不改 profile 的 `package.json` / `cordis.patch.yml`，不跑 pnpm，不做 git 操作。

## 9. 验收（可机械检查）

1. 目录能被 `plugin_manager` `install_bundle` 装进 `desktop` profile，`application: applied`，无 `failed`。
2. 装完后 `cordis_inspect_query`（client / Slots / `listSubTree`，root=`shell.overlay`）能看到 `registrant` 为我们包名的 `salary-flap` 条目且 `active: true`。
3. 金额格式永远是 `¥` + 两位小数；跨分钟、跨小时不出现 `NaN`、不出现 `¥-0.00`、不出现三位小数。
4. 每 2 秒结算一次：连续观察 10 秒，金额应跳 5 次左右，而不是每帧连续滚动。
5. 拖动、折叠、改参数后刷新页面，配置与位置都还在。
6. client.js 无语法错误：`node --check client.js` 通过（ESM 语法用 `node --input-type=module --check` 或 `node --check`，报错即返工）。

## 10. 网络对标结论（主控已搜，2026-10-25）

找到两个高度同类项目，只借鉴思路，不抄代码：

| 项目 | 是什么 | 借鉴 | 不借 |
|---|---|---|---|
| [MrBaoboer/PayDance](https://github.com/MrBaoboer/PayDance)「薪跳」 | Tauri 桌面实时工资看板，Vue3 | 月薪/日薪/时薪自动换算；迷你悬浮窗只显示金额、可拖动、可置顶；本地优先不联网；上班前 0、下班后封顶 | AGPL-3.0 代码一律不复制；午休剔除/夜班/托盘/自启不进 v1 |
| [HanLoney/SalaryTick](https://github.com/HanLoney/SalaryTick) | Python 单文件 Windows 桌面挂件 | 计算口径写得最干净：`日薪 = 月薪 / 每月计薪工作日`、`今日已赚 = 日薪 × 当前工作进度`；上班前归零、下班后封顶；跨午夜班次 | 不用 Python；星点/流光特效不进 v1 |

翻牌动画自己写（CSS 3D），不引外部库；只借鉴 split-flap 的「上半页下翻 + 下半页翻出」两段式结构。
